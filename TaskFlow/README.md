# TaskFlow



A task management web application built with ASP.NET Core MVC and C#.



## Features



- Task management

- ASP.NET Core MVC architecture

- Entity Framework Core

- SQL Server LocalDB



## Technologies



- C#

- ASP.NET Core MVC

- Entity Framework Core

- SQL Server LocalDB



## Getting Started



1\. Clone the repository.

2\. Open `TaskFlow.slnx` in Visual Studio.

3\. Ensure SQL Server LocalDB is installed.

4\. Check the database connection string in `appsettings.json`.

5\. Apply the Entity Framework Core migrations.

6\. Run the application.
